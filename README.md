The Hadassah House project is a professional, responsive web presence designed for community impact
My sister opened a learning center and required a working website for the state to recognize her business officially.
I created this website with her design input from start to finish entirely without additional assistance (and I'm very proud) 

Live Site: www.thehadassahhouse.com

Overview:
The Hadassah House website is a custom-built website designed to provide a streamlined,
accessible interface for users seeking information and community resources.
This project emphasizes clean typography, intuitive navigation, and mobile-first responsiveness (with acceptable pc form as well) 
to ensure a professional user experience across most devices.

Tech Stack:
Frontend: HTML5, CSS3, JavaScript(ES6+)

Hosting & DNS: Managed custom domain integration and hosting logistics

Design Philosophy: Focus on accessibility and readability for diverse user demographics.

Features:
-responsive layout
-Optimized performance (I was specifically shooting for a fast, non-aggravating experience for users)
-Brand Integration -She had specific color scheme and layout preferences.

Deployment:
-Coninuous Integration via Github Pages
-Regular audits for link integrity and cross-browser compatibility
